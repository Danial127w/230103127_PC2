# ParallelComputingMinimalLab

Python 3, standard library only. Run each phase separately:

```bash
python3 task0_cal.py
python3 task1_falsesharing.py
python3 task2_scaling.py
python3 task3_roofline_gemm.py
python3 task4_scheduling.py
```

Phase 3A and 3B are combined in `task3_roofline_gemm.py`, as required by the PDF. Some workloads are intentionally large and can take a long time. Record your own measured output and all five VERIFY_HASH lines in `lab_report_230103127.md`. Do not submit placeholder values as results.
